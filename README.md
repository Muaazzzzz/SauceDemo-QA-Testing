
# SauceDemo QA Automation Project

## About the Project
This project contains automated tests for the SauceDemo e-commerce website.

The goal is to practice QA automation, identify application issues, and build practical software testing experience.

## Technologies Used
- Python
- Playwright
- Pytest

## Test Scenarios
1. Successful login
2. Invalid login
3. Adding an item to the cart
4. Removing an item from the cart
5. Successful checkout
6. Checkout with missing first name
7. Checkout with missing last name
8. Checkout with missing postal code

## How to Run
Install the required packages:

pip install pytest pytest-playwright

Install Playwright browsers:

playwright install

Run the tests:

pytest
